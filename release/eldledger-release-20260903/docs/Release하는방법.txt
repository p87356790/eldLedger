다른 PC에서 쓸 수 있게 Docker 배포와 설치 안내를 준비했습니다. 브라우저는 http://localhost:8080 으로 접속합니다. (이 PC는 8080이 다른 프로그램이 쓰고 있어서 http://localhost:8180 으로 띄워 두었습니다.)

다른 PC에 설치

Docker Desktop 을 설치하고 실행합니다. Python/Node는 필요 없습니다.
release\eldledger-20260902.zip 을 풀거나, 이 프로젝트 폴더를 복사합니다.
start.bat 을 더블클릭합니다. 처음에는 이미지 받느라 인터넷이 필요하고 몇 분 걸릴 수 있습니다.
브라우저에서 관리자 계정을 만듭니다.
끄기는 stop.bat, 장부 백업은 backup.bat 입니다. 자세한 내용은 docs/INSTALL.md 와 README.md 에 있습니다.

장부 파일은 data\database\eldledger.db 에 남습니다. 쓰던 PC의 data 폴더를 함께 복사하면 기존 장부를 이어서 쓸 수 있습니다.
